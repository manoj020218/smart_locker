About SmartLocker by Jenix

SmartLocker by Jenix is a smart locker automation platform by IOTSoft, focused on electronics and software for locker, cabinet, vending machine, and battery swapping projects.

We are not a metal cabinet manufacturer. We provide the technology layer: electronic cabinet locks, RS485 / TCP-IP control cards, power and wiring guidance, access control logic, owner/admin app, user app/PWA, payment integration, and API/SDK connectivity.

What We Build

  • Smart electronic lock and cabinet automation hardware
  • Access modes: RFID card, PIN, face, QR, mobile app, admin unlock
  • UPI-based locker rental and usage workflows
  • Cloud + local EDGE architecture for online/offline operation
  • Integration support for OEM and white-label partners
